Understanding Balance Metrics

What is "Balance"?

Balance measures how evenly students are distributed across classes. Optimal balance means each class has the most even distribution possible given the number of students.

Balance Quality Ratings

  • Optimal: Best achievable distribution given class counts
  • Excellent: Very minor differences between classes
  • Good: Some variation but still well-balanced
  • Fair: Noticeable differences between classes

Understanding Balance Statistics

What do the numbers mean?

Each property (like IEP, gender, math level) shows how evenly students are distributed across classes using standard deviation (σ).

  • σ = 0: Optimal balance (all classes have equal numbers)
  • Higher σ: More unbalanced (some classes have more, some have fewer)

Theoretical Minimum (min)

The theoretical minimum is the best possible balance for your roster. If students divide evenly, it's 0. If not (e.g., 11 students across 5 classes), some classes must have more than others, so the minimum is slightly higher.

Goal: Get your dot as close to the left (min) as possible.

Theoretical Maximum (max)

The theoretical maximum is the worst-case scenario where all students of that type are in a single class. This is the right edge of the slider.

Using This While Dragging Students

As you drag students between classes, watch the sliders update in real-time. Try to move dots toward the left (green) side to improve balance!
